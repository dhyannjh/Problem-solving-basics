##THE SCENARIO

A school has 1000 lockers, all shut. On the first day, Student 1 walks down the corridor and opens every single locker. On the second day, Student 2 closes every second locker (2, 4, 6...). On day 3, Student 3 toggles every third locker (if open, close it; if closed, open it). This continues until Student 1000 has finished.

---

##THE CHALLENGE

#Part A

After all 1000 students have walked the corridor, which lockers are open? Write a program to find out.

#Part B

Why are those specific lockers open? Find the mathematical pattern — don't just list them, explain why.

#Part C
What if there were 10,000 lockers and 10,000 students? You should be able to answer this instantly without running any code.
